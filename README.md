# Huy’s graduation invitation
Static bilingual invitation for 26 November 2026. Open index.html or serve this folder with `python3 -m http.server 8000`.

Edit translations, date and map search in app.js; appearance in style.css. The time is tentative; countdown uses calendar days in Vietnam. Original portrait is preserved; portrait.webp is the optimized copy.

## GitHub Pages
Create a public repository named graduation under hillumie, upload index.html, style.css, app.js, portrait.webp, LICENSE and .nojekyll. In Settings → Pages, select Deploy from a branch → main → /(root). Intended URL: https://hillumie.github.io/graduation/ .

Standalone implementation. Layout and typography reference: HTML5 UP Story (https://html5up.net/uploads/demos/story/); no Story source or assets copied. The previously downloaded Rainier-PS template license is preserved in LICENSE.
